选择排序

选择排序本质上就是每次选出最值，比如说最小值，然后将最小值放到最左侧这样子的

大概是这样的

```
def select_sort:
    n= len(nums)
    for i in range(n-1):
        mini =i
        for j in range(i+1,n):
            if nums[j]<nums[mini]:
                mini=j
        nums[mini],nums[i] = nums[i],nums[mini]
    print(*nums)
```

冒泡排序

冒泡排序就是通过相邻两数之间的比较，得到更大值，然后让更大值向右移动

```
def bubble_sort:
    n=len(nums）
    for i in range(n-1):
        for j in range(n-i-1)
            if nums[j]>nums[j+1]:
                nums[j],nums[j+1]=nums[j+1],nums[j]
    print(*nums)

```
